# Samsung TV Local Power v0.2.2

Initial versioned, **experimental** distribution with a generic TV-power icon. Home Assistant runtime validation is still needed.

## Changes
- Custom icon at `custom_components/samsung_tv_true_power/brand/icon.png` (256 × 256).
- Local Samsung REST `PowerState` polling without cloud or remote pairing.
- Multi-TV configuration, binary state and diagnostic sensors.
- Generic examples and documentation, with a public privacy check.
- Semantic versioned GitHub release, including a ZIP suitable for manual installation.

## Install
Download the attached ZIP and copy its `custom_components/samsung_tv_true_power` directory into `/config/custom_components/`. Restart Home Assistant and add **Samsung TV Local Power** from Devices & services.

Requires a TV which exposes `device.PowerState` via `http://TV_IP:8001/api/v2/` with `on` / `standby` values. The integration does not determine the screen state through ping alone.

## Important
An unreachable API is not proof of standby. After the configured grace period, the binary sensor reports *presumed* OFF to avoid leaving lights on. Inspect the separate diagnostic state.
